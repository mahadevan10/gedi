# Gedi v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu-bar app where a pixel-art Thrissur guy ("Gedi") walks along the bottom of the screen, makes a passive-aggressive comment every 30 s in Thrissur-slang Malayalam about what the user is doing (using a local Qwen model in Ollama), and answers back when the user calls "gedeee".

**Architecture:** One SwiftPM package, no Xcode project. `GediCore` holds all pure logic and is unit-tested with Swift Testing. `GediSystem` wraps macOS services: the SpeechAnalyzer mic transcriber, AVAudioPlayer, AppleScript tab reading, and a child `piper.http_server` process for TTS. There are two executables: `Gedi` (the overlay and menu-bar app, bundled into `build/Gedi.app` by a script) and `gedi-debug` (a CLI that exercises each subsystem on its own).

**Tech Stack:** Swift 6.3 toolchain in Swift 5 language mode, SwiftUI + AppKit, Speech (`SpeechAnalyzer`/`SpeechTranscriber`, macOS 26+), AVFoundation, Ollama HTTP API (`qwen3.5:9b`), Piper TTS 1.8.0 (`ml_IN-arjun-medium`) in a uv-managed Python 3.12 venv.

3. **`ml-IN` output is romanized Malayalam (Manglish), not Malayalam script.** When Piper said "എന്തൂട്ടാ ഗഡീ ഇത്? പിന്നേം ഷോർട്സ്? …", it came back as `yenthootta gadiyitra pinneyum shorts aa tab onnu adachittu pani theerkk rishta`. The wake word came back as `gadhi`, `gadi`, `gadiye`, `gadeetha` and `gadiyitra`. That's why `WakeWordMatcher` does prefix matching on normalized Latin text. `mul-IN` gave identical output.
4. **macOS has no Malayalam TTS voice** (Tamil, Kannada, Telugu, Bengali and Hindi exist). Piper's `ml_IN-arjun-medium` voice (male, 63 MB) works:
   - 0.04–0.36 s per line via its HTTP server, using about 200 MB of RAM.
   - It reads Latin words and digits acceptably ("12" becomes "pantrandu").
5. **Piper/espeak-ng path-length bug:** if the path `…/site-packages/piper/espeak-ng-data` is longer than about 160 characters, Piper fails with `Error processing file '/Users/runner/work/piper1-gpl/…/phontab': No such file or directory`.
   - Seen in piper-tts 1.6.1, 1.7.0 and 1.8.0.
   - The venv location used here (`~/Library/Application Support/Gedi/piper-venv`) gives about 110 characters, which is fine. `setup.sh` smoke-tests it anyway.
6. **Piper HTTP API** (`python -m piper.http_server`, needs the `[http]` extra):
   - `POST /synthesize` with `{"text": "…"}` returns `audio/wav`.
   - `GET /info` returns 200 once the server is ready.
7. **Qwen on this Mac**, called through Ollama with `think: false` and a JSON-schema `format`:

   | model | RAM | speed | latency per line | quality |
   |---|---|---|---|---|
   | `qwen3.5:4b` | 3.1 GB | 26 tok/s | 3–8 s | Malayalam script and slang words, but more nonsense; once confused Reels with Shorts |
   | `qwen3.5:9b` | 5.6 GB | 17 tok/s | 6–13 s | More grounded (mentions the actual video, app and minutes); still some odd phrases |

   Both models are already pulled. The default is `qwen3.5:9b`, and Task 17 lets the user choose. Both fit inside the 30 s cycle.
8. **Ollama** listens at `http://127.0.0.1:11434` (Ollama.app has to be running). Its default context is 4096 tokens; Gedi's prompts are about 400–700 tokens.

Runtime files (not in the repo) live in `~/Library/Application Support/Gedi/`: `config.json`, `persona.md`, `clips/`, `piper-venv/` and `voices/`.

How a comment happens: every 5 s `ActivityProbe` reads the frontmost app or tab, and `ActivityLog` records it. Every 0.25 s `CommentPolicy` checks whether 30 s have passed since Gedi last spoke. If so, `GediBrain.comment` sends the activity summary to Ollama, `GediReply.parse` reads the JSON, and `GediVoice` plays a clip or Piper audio while the bubble shows the line.

How a conversation happens: `LiveTranscriber` streams mic results into `ListenSession`. A wake word triggers a chime and the "പറ ഗഡീ…" bubble. Then 1.5 s of silence ends the utterance, and `GediBrain.reply` answers. After Gedi speaks, an 8 s follow-up window accepts speech without the wake word. While Gedi is speaking (and for 0.7 s after) the mic is ignored, so he never wakes himself up.

import Foundation

/// User-tunable settings. Read from `~/Library/Application Support/Gedi/config.json`;
/// any key missing from the file falls back to `GediConfig.default`.
public struct GediConfig: Codable, Equatable, Sendable {
    public var model: String
    public var ollamaURL: URL
    public var commentIntervalSeconds: Double
    public var localeID: String
    public var wakeWords: [String]
    public var silenceSeconds: Double
    public var followUpSeconds: Double
    public var piperPython: String
    public var piperVoice: String
    public var piperDataDir: String
    public var piperPort: Int

    public init(
        model: String,
        ollamaURL: URL,
        commentIntervalSeconds: Double,
        localeID: String,
        wakeWords: [String],
        silenceSeconds: Double,
        followUpSeconds: Double,
        piperPython: String,
        piperVoice: String,
        piperDataDir: String,
        piperPort: Int
    ) {
        self.model = model
        self.ollamaURL = ollamaURL
        self.commentIntervalSeconds = commentIntervalSeconds
        self.localeID = localeID
        self.wakeWords = wakeWords
        self.silenceSeconds = silenceSeconds
        self.followUpSeconds = followUpSeconds
        self.piperPython = piperPython
        self.piperVoice = piperVoice
        self.piperDataDir = piperDataDir
        self.piperPort = piperPort
    }

    public static let `default` = GediConfig(
        model: "qwen3.5:9b",
        ollamaURL: URL(string: "http://127.0.0.1:11434")!,
        commentIntervalSeconds: 30,
        localeID: "ml-IN",
        wakeWords: ["gadi", "gadhi", "gade", "gedi", "gedhi", "gede", "ഗഡി", "ഗെഡി"],
        silenceSeconds: 1.5,
        followUpSeconds: 8,
        piperPython: "~/Library/Application Support/Gedi/piper-venv/bin/python",
        piperVoice: "ml_IN-arjun-medium",
        piperDataDir: "~/Library/Application Support/Gedi/voices",
        piperPort: 5917
    )

    public init(from decoder: Decoder) throws {
        let c = try decoder.container(keyedBy: CodingKeys.self)
        let d = GediConfig.default
        model = try c.decodeIfPresent(String.self, forKey: .model) ?? d.model
        ollamaURL = try c.decodeIfPresent(URL.self, forKey: .ollamaURL) ?? d.ollamaURL
        commentIntervalSeconds = try c.decodeIfPresent(Double.self, forKey: .commentIntervalSeconds) ?? d.commentIntervalSeconds
        localeID = try c.decodeIfPresent(String.self, forKey: .localeID) ?? d.localeID
        wakeWords = try c.decodeIfPresent([String].self, forKey: .wakeWords) ?? d.wakeWords
        silenceSeconds = try c.decodeIfPresent(Double.self, forKey: .silenceSeconds) ?? d.silenceSeconds
        followUpSeconds = try c.decodeIfPresent(Double.self, forKey: .followUpSeconds) ?? d.followUpSeconds
        piperPython = try c.decodeIfPresent(String.self, forKey: .piperPython) ?? d.piperPython
        piperVoice = try c.decodeIfPresent(String.self, forKey: .piperVoice) ?? d.piperVoice
        piperDataDir = try c.decodeIfPresent(String.self, forKey: .piperDataDir) ?? d.piperDataDir
        piperPort = try c.decodeIfPresent(Int.self, forKey: .piperPort) ?? d.piperPort
    }

    /// Missing file → defaults. Malformed file → throws (so a typo is reported, not silently ignored).
    public static func load(from url: URL) throws -> GediConfig {
        guard FileManager.default.fileExists(atPath: url.path) else { return .default }
        return try JSONDecoder().decode(GediConfig.self, from: Data(contentsOf: url))
    }
}

/// Where Gedi keeps user files.

    public static var supportDir: URL {
        FileManager.default.homeDirectoryForCurrentUser
            .appendingPathComponent("Library/Application Support/Gedi", isDirectory: true)
    }
    /// `GEDI_CONFIG=/path/to/config.json` overrides the location (handy for testing).
    public static var configFile: URL {
        if let override = ProcessInfo.processInfo.environment["GEDI_CONFIG"], !override.isEmpty {
            return URL(fileURLWithPath: expand(override))
        }
        return supportDir.appendingPathComponent("config.json")
    }
    public static var personaFile: URL { supportDir.appendingPathComponent("persona.md") }
    public static var clipsDir: URL { supportDir.appendingPathComponent("clips", isDirectory: true) }

    /// Expands a leading `~` in paths from the config file.
    public static func expand(_ path: String) -> String {
        (path as NSString).expandingTildeInPath
    }
}

import Foundation

/// One observation of what is in front of the user.
public struct ActivitySnapshot: Equatable, Sendable {
    public var appName: String
    public var bundleID: String
    public var url: String?
    public var title: String?

    public init(appName: String, bundleID: String, url: String? = nil, title: String? = nil) {
        self.appName = appName
        self.bundleID = bundleID
        self.url = url
        self.title = title
    }
}

public enum ActivityKind: String, Equatable, Sendable {
    case shortVideo, video, social, chat, coding, call, other
}

/// A snapshot reduced to what Gedi cares about.
/// `name` is the key time is totalled under ("YouTube Shorts", "Visual Studio Code");
/// `detail` is the page title, used only for the "Now:" line.
public struct ClassifiedActivity: Equatable, Sendable {
    public var kind: ActivityKind
    public var name: String
    public var detail: String?

    public init(kind: ActivityKind, name: String, detail: String? = nil) {
        self.kind = kind
        self.name = name
        self.detail = detail
    }
}

public enum ActivityClassifier {
    public static func classify(_ s: ActivitySnapshot) -> ClassifiedActivity {
        if let raw = s.url, let url = URL(string: raw), let host = url.host?.lowercased() {
            return classifyWeb(host: strip(host), path: url.path.lowercased(), title: s.title, appName: s.appName)
        }
        return ClassifiedActivity(kind: appKind(s.bundleID), name: s.appName, detail: s.title)
    }

    private static func strip(_ host: String) -> String {
        for prefix in ["www.", "m."] where host.hasPrefix(prefix) {
            return String(host.dropFirst(prefix.count))
        }
        return host
    }

    private static func classifyWeb(host: String, path: String, title: String?, appName: String) -> ClassifiedActivity {
        func make(_ kind: ActivityKind, _ name: String) -> ClassifiedActivity {
            ClassifiedActivity(kind: kind, name: name, detail: title)
        }
        switch host {
        case "youtube.com":
            if path.hasPrefix("/shorts") { return make(.shortVideo, "YouTube Shorts") }
            return make(.video, "YouTube")
        case "instagram.com":
            if path.hasPrefix("/reels") || path.hasPrefix("/reel/") { return make(.shortVideo, "Instagram Reels") }
            return make(.social, "Instagram")
        case "facebook.com":
            if path.hasPrefix("/reel") { return make(.shortVideo, "Facebook Reels") }
            return make(.social, "Facebook")
        case "tiktok.com": return make(.shortVideo, "TikTok")
        case "netflix.com": return make(.video, "Netflix")
        case "primevideo.com": return make(.video, "Prime Video")
        case "hotstar.com", "jiohotstar.com": return make(.video, "Hotstar")
        case "x.com", "twitter.com": return make(.social, "X")
        case "reddit.com": return make(.social, "Reddit")
        case "linkedin.com": return make(.social, "LinkedIn")
        case "meet.google.com": return make(.call, "Google Meet")
        case "web.whatsapp.com": return make(.chat, "WhatsApp")
        case "web.telegram.org": return make(.chat, "Telegram")
        case "discord.com": return make(.chat, "Discord")
        case "app.slack.com": return make(.chat, "Slack")
        case "github.com": return make(.coding, "GitHub")
        case "stackoverflow.com": return make(.coding, "Stack Overflow")
        case "developer.apple.com": return make(.coding, "Apple Developer docs")
        case "localhost", "127.0.0.1": return make(.coding, "localhost")
        default: return make(.other, host)
        }
    }

    private static let codingApps: Set<String> = [
        "com.microsoft.VSCode", "com.apple.dt.Xcode", "com.todesktop.230313mzl4w4u92",
        "com.apple.Terminal", "com.googlecode.iterm2", "dev.warp.Warp-Stable", "com.mitchellh.ghostty",
    ]
    private static let callApps: Set<String> = [
        "us.zoom.xos", "com.apple.FaceTime", "com.microsoft.teams2", "com.microsoft.teams",
    ]
    private static let chatApps: Set<String> = [
        "net.whatsapp.WhatsApp", "com.tinyspeck.slackmacgap", "ru.keepcoder.Telegram", "com.hnc.Discord",
    ]

    private static func appKind(_ bundleID: String) -> ActivityKind {
        if codingApps.contains(bundleID) || bundleID.hasPrefix("com.jetbrains.") { return .coding }
        if callApps.contains(bundleID) { return .call }
        if chatApps.contains(bundleID) { return .chat }
        return .other
    }
}

````swift
import Foundation

/// Rolling record of what the user has been doing, built from periodic snapshots.
/// Each `record` call closes the previous entry at `time` and either extends it
/// (same activity) or starts a new one. Gaps longer than `maxGap` (sleep, lock screen)
/// are not counted as activity.
public struct ActivityLog: Sendable {
    public struct Entry: Equatable, Sendable {
        public var activity: ClassifiedActivity
        public var start: Date
        public var end: Date
    }

    public private(set) var entries: [Entry] = []
    public var maxGap: TimeInterval
    public var retention: TimeInterval

    public init(maxGap: TimeInterval = 30, retention: TimeInterval = 3600) {
        self.maxGap = maxGap
        self.retention = retention
    }

    public mutating func record(_ activity: ClassifiedActivity, at time: Date) {
        if var last = entries.last, time.timeIntervalSince(last.end) <= maxGap {
            last.end = time
            if last.activity.name == activity.name && last.activity.kind == activity.kind {
                last.activity.detail = activity.detail
                entries[entries.count - 1] = last
            } else {
                entries[entries.count - 1] = last
                entries.append(Entry(activity: activity, start: time, end: time))
            }
        } else {
            entries.append(Entry(activity: activity, start: time, end: time))
        }
        let cutoff = time.addingTimeInterval(-retention)
        entries.removeAll { $0.end < cutoff }
    }

    /// The activity the user is on now, if the last snapshot is recent.
    public func current(now: Date) -> ClassifiedActivity? {
        guard let last = entries.last, now.timeIntervalSince(last.end) <= maxGap else { return nil }
        return last.activity
    }

    public func summary(now: Date, window: TimeInterval = 900) -> ActivitySummary {
        let windowStart = now.addingTimeInterval(-window)
        var order: [String] = []
        var totals: [String: (ActivityKind, TimeInterval)] = [:]
        for e in entries {
            let s = max(e.start, windowStart)
            let t = min(e.end, now)
            guard t > s else { continue }
            if totals[e.activity.name] == nil { order.append(e.activity.name) }
            let prev = totals[e.activity.name]?.1 ?? 0
            totals[e.activity.name] = (e.activity.kind, prev + t.timeIntervalSince(s))
        }
        let list = order
            .map { ActivitySummary.Total(name: $0, kind: totals[$0]!.0, seconds: totals[$0]!.1) }
            .sorted { $0.seconds > $1.seconds }
        var streak: TimeInterval = 0
        let cur = current(now: now)
        if cur != nil, let last = entries.last { streak = now.timeIntervalSince(last.start) }
        return ActivitySummary(now: now, current: cur, currentStreak: streak, totals: list)
    }
}

public struct ActivitySummary: Equatable, Sendable {
    public struct Total: Equatable, Sendable {
        public var name: String
        public var kind: ActivityKind
        public var seconds: TimeInterval
    }

    public var now: Date
    public var current: ClassifiedActivity?
    public var currentStreak: TimeInterval
    public var totals: [Total]

    public var isInCall: Bool { current?.kind == .call }

    /// The block of text the LLM sees, e.g.
    /// ```
    /// Now: YouTube Shorts — "funny cat" (for 6 min straight)
    /// Last 15 min: YouTube Shorts 12 min, Visual Studio Code 3 min
    /// Local time: Tue 23:40
    /// ```
    public func promptText(timeZone: TimeZone = .current) -> String {
        var lines: [String] = []
        if let c = current {
            var now = "Now: \(c.name)"
            if let d = c.detail, !d.isEmpty, d != c.name { now += " — \"\(String(d.prefix(80)))\"" }
            now += " (for \(Self.minutes(currentStreak)) straight)"
            lines.append(now)
        } else {
            lines.append("Now: away from the computer")
        }
        if !totals.isEmpty {
            let parts = totals.prefix(5).map { "\($0.name) \(Self.minutes($0.seconds))" }
            lines.append("Last 15 min: " + parts.joined(separator: ", "))
        }
        let f = DateFormatter()
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = timeZone
        f.dateFormat = "EEE HH:mm"
        lines.append("Local time: \(f.string(from: now))")
        return lines.joined(separator: "\n")
    }

    static func minutes(_ seconds: TimeInterval) -> String {
        seconds < 60 ? "<1 min" : "\(Int((seconds / 60).rounded())) min"
    }
}

import Foundation

/// Minimal JSON value, used to send a JSON schema to Ollama's `format` field.
public indirect enum JSON: Codable, Equatable, Sendable {
    case string(String)
    case number(Double)
    case bool(Bool)
    case array([JSON])
    case object([String: JSON])
    case null

    public func encode(to encoder: Encoder) throws {
        var c = encoder.singleValueContainer()
        switch self {
        case .string(let v): try c.encode(v)
        case .number(let v): try c.encode(v)
        case .bool(let v): try c.encode(v)
        case .array(let v): try c.encode(v)
        case .object(let v): try c.encode(v)
        case .null: try c.encodeNil()
        }
    }

    public init(from decoder: Decoder) throws {
        let c = try decoder.singleValueContainer()
        if c.decodeNil() { self = .null }
        else if let v = try? c.decode(Bool.self) { self = .bool(v) }
        else if let v = try? c.decode(Double.self) { self = .number(v) }
        else if let v = try? c.decode(String.self) { self = .string(v) }
        else if let v = try? c.decode([JSON].self) { self = .array(v) }
        else { self = .object(try c.decode([String: JSON].self)) }
    }
}

```swift
import Foundation

/// What the LLM decided to say. `speak == false` means "stay quiet this time".
/// `clip` is the id of a pre-recorded clip to play instead of synthesising `line`.
public struct GediReply: Codable, Equatable, Sendable {
    public var speak: Bool
    public var line: String
    public var clip: String?

    public init(speak: Bool, line: String, clip: String? = nil) {
        self.speak = speak
        self.line = line
        self.clip = clip
    }

    /// Lenient parser for model output. Accepts clean JSON, JSON wrapped in other text,
    /// or (as a last resort) bare Malayalam text. Returns nil for anything unusable.
    public static func parse(_ raw: String) -> GediReply? {
        let text = raw.trimmingCharacters(in: .whitespacesAndNewlines)
        if let r = decode(text) { return r }
        if let open = text.firstIndex(of: "{"), let close = text.lastIndex(of: "}"), open < close,
           let r = decode(String(text[open...close])) {
            return r
        }
        if text.unicodeScalars.contains(where: { (0x0D00...0x0D7F).contains($0.value) }) {
            return GediReply(speak: true, line: text)
        }
        return nil
    }

    private static func decode(_ s: String) -> GediReply? {
        guard var r = try? JSONDecoder().decode(GediReply.self, from: Data(s.utf8)) else { return nil }
        r.line = r.line.trimmingCharacters(in: .whitespacesAndNewlines)
        if let c = r.clip?.trimmingCharacters(in: .whitespaces), c.isEmpty || c == "none" { r.clip = nil }
        if r.line.isEmpty && r.clip == nil { r.speak = false }
        return r
    }
}

import Foundation

/// A line the user recorded in their own Thrissur voice.
/// `use` tells the LLM when the clip fits ("user is on Shorts or Reels").
public struct ClipInfo: Codable, Equatable, Sendable {
    public var id: String
    public var file: String
    public var text: String
    public var use: String

    public init(id: String, file: String, text: String, use: String) {
        self.id = id
        self.file = file
        self.text = text
        self.use = use
    }
}

/// The clips folder: `clips.json` (an array of `ClipInfo`) plus the audio files it names.
public struct ClipLibrary: Sendable {
    public let directory: URL
    /// Only clips whose audio file exists.
    public let clips: [ClipInfo]

    public init(directory: URL, clips: [ClipInfo]) {
        self.directory = directory
        self.clips = clips
    }

    public static func empty(at directory: URL) -> ClipLibrary {
        ClipLibrary(directory: directory, clips: [])
    }

    /// No manifest → empty library. Malformed manifest → throws.
    public static func load(from directory: URL) throws -> ClipLibrary {
        let manifest = directory.appendingPathComponent("clips.json")
        guard FileManager.default.fileExists(atPath: manifest.path) else { return .empty(at: directory) }
        let all = try JSONDecoder().decode([ClipInfo].self, from: Data(contentsOf: manifest))
        let present = all.filter {
            FileManager.default.fileExists(atPath: directory.appendingPathComponent($0.file).path)
        }
        return ClipLibrary(directory: directory, clips: present)
    }

    public func clip(id: String) -> ClipInfo? { clips.first { $0.id == id } }

    public func url(for clip: ClipInfo) -> URL { directory.appendingPathComponent(clip.file) }
}

import Foundation

public struct ChatMessage: Codable, Equatable, Sendable {
    public var role: String
    public var content: String

    public init(role: String, content: String) {
        self.role = role
        self.content = content
    }

    public static func system(_ s: String) -> ChatMessage { ChatMessage(role: "system", content: s) }
    public static func user(_ s: String) -> ChatMessage { ChatMessage(role: "user", content: s) }
    public static func assistant(_ s: String) -> ChatMessage { ChatMessage(role: "assistant", content: s) }
}

/// Turns persona + activity + history into Ollama chat messages and a reply schema.
public struct PromptBuilder: Sendable {
    public var persona: String
    public var clips: [ClipInfo]

    public init(persona: String, clips: [ClipInfo] = []) {
        self.persona = persona
        self.clips = clips
    }

    public func systemPrompt() -> String {
        var rules = """
        ## Output rules (always follow)
        - Reply with JSON only: {"speak": true or false, "line": "<what you say>", "clip": "<clip id or none>"}
        - "line" is Malayalam script only, at most 2 short sentences.
        - Never repeat or reword one of your recent lines. Say something new.
        - Set "speak" to false only if you truly have nothing to say.
        """
        if clips.isEmpty {
            rules += "\n- Always set \"clip\" to \"none\"."
        } else {
            rules += "\n- \"clip\": the id of one recorded clip below if it fits the moment perfectly, otherwise \"none\". When you pick a clip, put its text in \"line\"."
            rules += "\n\nRecorded clips:"
            for c in clips {
                rules += "\n- \(c.id): \"\(c.text)\" (use when: \(c.use))"
            }
        }
        return persona.trimmingCharacters(in: .whitespacesAndNewlines) + "\n\n" + rules
    }

    /// Unprompted comment on the timer.
    public func commentMessages(activity: String, recentLines: [String]) -> [ChatMessage] {
        var user = "What the user is doing:\n\(activity)\n\n"
        if recentLines.isEmpty {
            user += "You have not said anything yet.\n"
        } else {
            user += "Your recent lines (do not repeat these):\n"
            user += recentLines.map { "- \($0)" }.joined(separator: "\n") + "\n"
        }
        user += "\nSay one new short line about what they are doing right now."
        return [.system(systemPrompt()), .user(user)]
    }

    /// Reply when the user called "gedeee" and said something.
    /// `conversation` holds earlier user/assistant turns of this chat.
    public func replyMessages(activity: String, utterance: String, conversation: [ChatMessage]) -> [ChatMessage] {
        let user = """
        What the user is doing:
        \(activity)

        The user just called you and said: "\(utterance)"
        (Their words come from speech recognition, written in Manglish, and may contain mistakes.)
        Reply to them directly.
        """
        return [.system(systemPrompt())] + conversation + [.user(user)]
    }

    /// JSON schema for Ollama's `format`, restricting `clip` to known ids.
    public func responseSchema() -> JSON {
        .object([
            "type": .string("object"),
            "properties": .object([
                "speak": .object(["type": .string("boolean")]),
                "line": .object(["type": .string("string")]),
                "clip": .object([
                    "type": .string("string"),
                    "enum": .array(([JSON.string("none")]) + clips.map { .string($0.id) }),
                ]),
            ]),
            "required": .array([.string("speak"), .string("line"), .string("clip")]),
        ])
    }
}

import Foundation

/// Intercepts URLSession requests in tests. Each test uses its own `host` key so
/// tests running in parallel do not see each other's stubs.
final class StubURLProtocol: URLProtocol, @unchecked Sendable {
    struct Stub {
        var status: Int
        var body: Data
    }

    nonisolated(unsafe) private static var stubs: [String: Stub] = [:]
    nonisolated(unsafe) private static var captured: [String: URLRequest] = [:]
    nonisolated(unsafe) private static var capturedBodies: [String: Data] = [:]
    private static let lock = NSLock()

    static func session() -> URLSession {
        let config = URLSessionConfiguration.ephemeral
        config.protocolClasses = [StubURLProtocol.self]
        return URLSession(configuration: config)
    }

    static func stub(host: String, status: Int = 200, body: Data) {
        lock.withLock { stubs[host] = Stub(status: status, body: body) }
    }

    static func lastRequest(host: String) -> (URLRequest, Data)? {
        lock.withLock {
            guard let r = captured[host] else { return nil }
            return (r, capturedBodies[host] ?? Data())
        }
    }

    override class func canInit(with request: URLRequest) -> Bool { true }
    override class func canonicalRequest(for request: URLRequest) -> URLRequest { request }

    override func startLoading() {
        let host = request.url?.host ?? ""
        let body = request.httpBody ?? Self.readStream(request.httpBodyStream)
        let stub: Stub? = Self.lock.withLock {
            Self.captured[host] = request
            Self.capturedBodies[host] = body
            return Self.stubs[host]
        }
        guard let stub else {
            client?.urlProtocol(self, didFailWithError: URLError(.cannotConnectToHost))
            return
        }
        let response = HTTPURLResponse(url: request.url!, statusCode: stub.status, httpVersion: nil, headerFields: nil)!
        client?.urlProtocol(self, didReceive: response, cacheStoragePolicy: .notAllowed)
        client?.urlProtocol(self, didLoad: stub.body)
        client?.urlProtocolDidFinishLoading(self)
    }

    override func stopLoading() {}

    private static func readStream(_ stream: InputStream?) -> Data {
        guard let stream else { return Data() }
        stream.open()
        defer { stream.close() }
        var data = Data()
        var buffer = [UInt8](repeating: 0, count: 4096)
        while stream.hasBytesAvailable {
            let n = stream.read(&buffer, maxLength: buffer.count)
            if n <= 0 { break }
            data.append(buffer, count: n)
        }
        return data
    }
}

import Foundation

/// Anything that can turn chat messages into a raw reply string. Lets tests swap in a fake.
public protocol ChatModel: Sendable {
    func chat(_ messages: [ChatMessage], schema: JSON) async throws -> String
}

public enum OllamaError: Error, Equatable {
    case http(status: Int, body: String)
}

/// Calls Ollama's `/api/chat` with streaming and thinking off and a JSON-schema `format`.
public struct OllamaClient: ChatModel {
    public var baseURL: URL
    public var model: String
    public var session: URLSession
    public var temperature: Double = 0.9
    public var maxTokens: Int = 160
    public var contextLength: Int = 4096
    /// Keeps the model loaded between the 30 s comments so there is no reload delay.
    public var keepAlive: String = "30m"

    public init(baseURL: URL, model: String, session: URLSession = .shared) {
        self.baseURL = baseURL
        self.model = model
        self.session = session
    }

    struct Request: Encodable {
        struct Options: Encodable {
            let temperature: Double
            let num_predict: Int
            let num_ctx: Int
        }
        let model: String
        let messages: [ChatMessage]
        let stream: Bool
        let think: Bool
        let format: JSON
        let keep_alive: String
        let options: Options
    }

    struct Response: Decodable {
        struct Message: Decodable { let content: String }
        let message: Message
    }

    public func chat(_ messages: [ChatMessage], schema: JSON) async throws -> String {
        var req = URLRequest(url: baseURL.appendingPathComponent("api/chat"))
        req.httpMethod = "POST"
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        req.timeoutInterval = 120
        req.httpBody = try JSONEncoder().encode(Request(
            model: model,
            messages: messages,
            stream: false,
            think: false,
            format: schema,
            keep_alive: keepAlive,
            options: .init(temperature: temperature, num_predict: maxTokens, num_ctx: contextLength)
        ))
        let (data, response) = try await session.data(for: req)
        let status = (response as? HTTPURLResponse)?.statusCode ?? -1
        guard status == 200 else {
            throw OllamaError.http(status: status, body: String(decoding: data, as: UTF8.self))
        }
        return try JSONDecoder().decode(Response.self, from: data).message.content
    }
}

import Foundation

/// Decides what Gedi says. Remembers its own recent lines (to avoid repeats) and the
/// current conversation (so follow-up questions make sense).
public actor GediBrain {
    private let model: any ChatModel
    private var builder: PromptBuilder
    public private(set) var recentLines: [String] = []
    public private(set) var conversation: [ChatMessage] = []
    private let maxRecentLines = 5
    private let maxConversationMessages = 6

    public init(model: any ChatModel, builder: PromptBuilder) {
        self.model = model
        self.builder = builder
    }

    public func updateClips(_ clips: [ClipInfo]) {
        builder.clips = clips
    }

    /// Unprompted comment about the activity. Nil if the model output was unusable.
    public func comment(activity: String) async throws -> GediReply? {
        let messages = builder.commentMessages(activity: activity, recentLines: recentLines)
        let raw = try await model.chat(messages, schema: builder.responseSchema())
        guard let reply = GediReply.parse(raw) else { return nil }
        if reply.speak { remember(reply.line) }
        return reply
    }

    /// Answer to something the user said after "gedeee".
    public func reply(to utterance: String, activity: String) async throws -> GediReply? {
        let messages = builder.replyMessages(activity: activity, utterance: utterance, conversation: conversation)
        let raw = try await model.chat(messages, schema: builder.responseSchema())
        guard let reply = GediReply.parse(raw) else { return nil }
        conversation.append(.user(utterance))
        conversation.append(.assistant(Self.encode(reply)))
        if conversation.count > maxConversationMessages {
            conversation.removeFirst(conversation.count - maxConversationMessages)
        }
        if reply.speak { remember(reply.line) }
        return reply
    }

    /// Forget the conversation once the user has stopped talking to Gedi.
    public func endConversation() {
        conversation.removeAll()
    }

    private func remember(_ line: String) {
        recentLines.append(line)
        if recentLines.count > maxRecentLines { recentLines.removeFirst() }
    }

    private static func encode(_ reply: GediReply) -> String {
        var r = reply
        if r.clip == nil { r.clip = "none" }
        let enc = JSONEncoder()
        enc.outputFormatting = .sortedKeys
        return (try? String(decoding: enc.encode(r), as: UTF8.self)) ?? reply.line
    }
}

import Foundation

/// Finds "gedeee" in recognised text.
///
/// Apple's ml-IN recogniser writes Malayalam in Latin letters (Manglish), and it spells
/// the call several ways: "gadhi", "gadi", "gadiye", and sometimes glues it to the next
/// word ("gadiyitra" for "ഗഡീ ഇത്"). So a word matches when, after normalising, it
/// *starts with* one of the wake words. Normalising = lowercase, drop zero-width joiners,
/// long ീ → short ി, collapse repeated characters ("gadeee" → "gade", "geddi" → "gedi").
public struct WakeWordMatcher: Sendable {
    private let prefixes: [String]

    public init(wakeWords: [String]) {
        prefixes = wakeWords.map(Self.normalize).filter { !$0.isEmpty }
    }

    public static func normalize(_ s: String) -> String {
        var out = String.UnicodeScalarView()
        var previous: Unicode.Scalar?
        for scalar in s.lowercased().unicodeScalars {
            if scalar.value == 0x200C || scalar.value == 0x200D { continue }
            let mapped: Unicode.Scalar = scalar.value == 0x0D40 ? Unicode.Scalar(0x0D3F)! : scalar
            if mapped == previous { continue }
            out.append(mapped)
            previous = mapped
        }
        return String(out)
    }

    private static let separators = CharacterSet.whitespacesAndNewlines.union(.punctuationCharacters)

    /// Nil if there is no wake word. Otherwise the text after the word that contained it,
    /// trimmed ("" when the user said only "gedeee").
    public func remainder(after text: String) -> String? {
        let tokens = text.split(whereSeparator: { c in
            c.unicodeScalars.allSatisfy { Self.separators.contains($0) }
        })
        for token in tokens {
            let word = Self.normalize(String(token))
            if prefixes.contains(where: { word.hasPrefix($0) }) {
                return String(text[token.endIndex...]).trimmingCharacters(in: Self.separators)
            }
        }
        return nil
    }
}

```swift
import Foundation

public enum ListenEvent: Equatable, Sendable {
    /// Wake word heard. Show "listening", play a chime.
    case wake
    /// The user finished speaking. Send this text to the brain.
    case utterance(String)
    /// Wake word with nothing after it, or the follow-up window passed. Back to idle.
    case gaveUp
}

/// Turns a stream of transcription results into wake / utterance events.
///
/// The speech recogniser runs all the time. Each result is the latest guess for the
/// current stretch of speech (`isFinal == false`) or the settled text for it (`isFinal == true`).
/// The user is considered done when the captured text has not changed for `silence` seconds.
///
/// While Gedi is speaking (and `echoTail` seconds after) everything is ignored, so Gedi
/// never wakes itself up by saying "ഗഡീ".
public struct ListenSession: Sendable {
    public enum Phase: Equatable, Sendable {
        case idle, capturing, waitingForReply, followUp
    }

    public private(set) var phase: Phase = .idle
    public var silence: TimeInterval
    public var followUpWindow: TimeInterval
    public var maxWaitAfterWake: TimeInterval = 6
    public var echoTail: TimeInterval = 0.7

    private let matcher: WakeWordMatcher
    private var committed: [String] = []
    private var pending = ""
    private var lastChange = Date.distantPast
    private var phaseStarted = Date.distantPast
    private var speaking = false
    private var deafUntil = Date.distantPast

    public init(matcher: WakeWordMatcher, silence: TimeInterval = 1.5, followUpWindow: TimeInterval = 8) {
        self.matcher = matcher
        self.silence = silence
        self.followUpWindow = followUpWindow
    }

    public var capturedText: String {
        (committed + [pending]).filter { !$0.isEmpty }.joined(separator: " ")
    }

    public mutating func heard(_ text: String, isFinal: Bool, at now: Date) -> ListenEvent? {
        if speaking || now < deafUntil { return nil }
        switch phase {
        case .idle:
            guard let rest = matcher.remainder(after: text) else { return nil }
            enterCapturing(at: now)
            absorb(rest, isFinal: isFinal, at: now)
            return .wake
        case .followUp:
            let piece = matcher.remainder(after: text) ?? text
            guard !piece.trimmingCharacters(in: .whitespaces).isEmpty else { return nil }
            enterCapturing(at: now)
            absorb(piece, isFinal: isFinal, at: now)
            return nil
        case .capturing:
            absorb(matcher.remainder(after: text) ?? text, isFinal: isFinal, at: now)
            return nil
        case .waitingForReply:
            return nil
        }
    }

    /// Call about every 0.25–1 s.
    public mutating func tick(at now: Date) -> ListenEvent? {
        switch phase {
        case .capturing:
            let text = capturedText
            if text.isEmpty {
                if now.timeIntervalSince(phaseStarted) >= maxWaitAfterWake {
                    phase = .idle
                    return .gaveUp
                }
            } else if now.timeIntervalSince(lastChange) >= silence {
                phase = .waitingForReply
                return .utterance(text)
            }
        case .followUp:
            if now.timeIntervalSince(phaseStarted) >= followUpWindow {
                phase = .idle
                return .gaveUp
            }
        case .idle, .waitingForReply:
            break
        }
        return nil
    }

    public mutating func speakingStarted() {
        speaking = true
    }

    /// Call when Gedi stops talking. Also call it when a reply failed and nothing was
    /// said, so the session leaves `waitingForReply`.
    public mutating func speakingEnded(at now: Date) {
        speaking = false
        deafUntil = now.addingTimeInterval(echoTail)
        if phase == .waitingForReply {
            phase = .followUp
            phaseStarted = now
        }
    }

    private mutating func enterCapturing(at now: Date) {
        phase = .capturing
        committed = []
        pending = ""
        phaseStarted = now
        lastChange = now
    }

    private mutating func absorb(_ piece: String, isFinal: Bool, at now: Date) {
        let before = capturedText
        let trimmed = piece.trimmingCharacters(in: .whitespaces)
        if isFinal {
            if !trimmed.isEmpty { committed.append(trimmed) }
            pending = ""
        } else {
            pending = trimmed
        }
        if capturedText != before { lastChange = now }
    }
}

import Foundation

public enum PiperError: Error, Equatable {
    case http(status: Int, body: String)
    case notWAV
}

/// Talks to `python -m piper.http_server`. POST /synthesize {"text": …} → WAV bytes.
public struct PiperClient: Sendable {
    public var baseURL: URL
    public var session: URLSession

    public init(baseURL: URL, session: URLSession = .shared) {
        self.baseURL = baseURL
        self.session = session
    }

    public init(port: Int, session: URLSession = .shared) {
        self.init(baseURL: URL(string: "http://127.0.0.1:\(port)")!, session: session)
    }

    public func synthesize(_ text: String) async throws -> Data {
        var req = URLRequest(url: baseURL.appendingPathComponent("synthesize"))
        req.httpMethod = "POST"
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        req.timeoutInterval = 30
        req.httpBody = try JSONEncoder().encode(["text": text])
        let (data, response) = try await session.data(for: req)
        let status = (response as? HTTPURLResponse)?.statusCode ?? -1
        guard status == 200 else {
            throw PiperError.http(status: status, body: String(decoding: data.prefix(500), as: UTF8.self))
        }
        guard data.count > 44, data.prefix(4) == Data("RIFF".utf8) else { throw PiperError.notWAV }
        return data
    }

    /// True once the server answers GET /info.
    public func isReady() async -> Bool {
        var req = URLRequest(url: baseURL.appendingPathComponent("info"))
        req.timeoutInterval = 2
        guard let (_, response) = try? await session.data(for: req) else { return false }
        return (response as? HTTPURLResponse)?.statusCode == 200
    }
}

import Foundation

/// v1 rule for unprompted comments: every `interval` seconds, measured from the end of
/// Gedi's last speech, unless something says to stay quiet. Later versions can replace
/// this with "let the model decide" (GediReply.speak already supports that).
public struct CommentPolicy: Sendable {
    public var interval: TimeInterval

    public init(interval: TimeInterval) {
        self.interval = interval
    }

    public struct State: Sendable {
        public var muted = false
        /// Generating or speaking right now.
        public var busy = false
        /// The user is talking to Gedi (wake word heard, follow-up window open).
        public var conversing = false
        public var inCall = false
        public init() {}
    }

    public func isDue(now: Date, lastSpokeAt: Date, state: State) -> Bool {
        if state.muted || state.busy || state.conversing || state.inCall { return false }
        return now.timeIntervalSince(lastSpokeAt) >= interval
    }
}

import Foundation

/// Gedi's movement along the bottom of the screen. Pure state, advanced by `step`.
/// Walks at `speed` points/s, turns at the edges, pauses now and then, and stops
/// to face the user while talking.
public struct Walker: Sendable {
    public enum Mode: Equatable, Sendable {
        case walking
        case resting(until: TimeInterval)
        case talking
    }

    public private(set) var x: Double
    public private(set) var facingRight: Bool
    public private(set) var mode: Mode = .walking
    public var speed: Double = 40
    /// Chance per second of stopping for a rest while walking.
    public var restChancePerSecond: Double = 0.08
    private var clock: TimeInterval = 0

    public init(x: Double, facingRight: Bool = true) {
        self.x = x
        self.facingRight = facingRight
    }

    public mutating func step<R: RandomNumberGenerator>(dt: Double, minX: Double, maxX: Double, random: inout R) {
        clock += dt
        switch mode {
        case .talking:
            return
        case .resting(let until):
            if clock >= until {
                mode = .walking
                if Double.random(in: 0..<1, using: &random) < 0.5 { facingRight.toggle() }
            }
        case .walking:
            x += (facingRight ? speed : -speed) * dt
            if x >= maxX {
                x = maxX
                facingRight = false
            } else if x <= minX {
                x = minX
                facingRight = true
            } else if Double.random(in: 0..<1, using: &random) < restChancePerSecond * dt {
                mode = .resting(until: clock + Double.random(in: 2...6, using: &random))
            }
        }
    }

    public mutating func setTalking(_ talking: Bool) {
        if talking {
            mode = .talking
        } else if mode == .talking {

public enum PiperServerError: Error, CustomStringConvertible {
    case pythonMissing(String)
    case voiceMissing(String)
    case notReady(log: String)

    public var description: String {
        switch self {
        case .pythonMissing(let p): return "Piper Python not found at \(p). Run scripts/setup.sh."
        case .voiceMissing(let p): return "Piper voice not found at \(p). Run scripts/setup.sh."

/// Runs `python -m piper.http_server` as a child process so the voice stays loaded.
/// If something already answers on the port (e.g. left over from a crash), it is reused.
public final class PiperServer: @unchecked Sendable {
    private let config: GediConfig
    private var process: Process?
    private let logURL = FileManager.default.temporaryDirectory.appendingPathComponent("gedi-piper.log")
    public let client: PiperClient

    public init(config: GediConfig) {
        self.config = config
        self.client = PiperClient(port: config.piperPort)
    }

    public func start(timeout: TimeInterval = 20) async throws {
        if await client.isReady() { return }
        let python = GediPaths.expand(config.piperPython)
        let dataDir = GediPaths.expand(config.piperDataDir)
        let voice = "\(dataDir)/\(config.piperVoice).onnx"
        guard FileManager.default.isExecutableFile(atPath: python) else { throw PiperServerError.pythonMissing(python) }
        guard FileManager.default.fileExists(atPath: voice) else { throw PiperServerError.voiceMissing(voice) }

        FileManager.default.createFile(atPath: logURL.path, contents: nil)
        let log = try FileHandle(forWritingTo: logURL)
        let p = Process()
        p.executableURL = URL(fileURLWithPath: python)
        p.arguments = ["-m", "piper.http_server", "-m", config.piperVoice, "--data-dir", dataDir,
                       "--host", "127.0.0.1", "--port", String(config.piperPort)]
        p.standardOutput = log
        p.standardError = log
        try p.run()
        process = p

        let deadline = Date().addingTimeInterval(timeout)
        while Date() < deadline {
            if await client.isReady() { return }
            if !p.isRunning { break }
            try await Task.sleep(for: .milliseconds(250))
        }
        stop()
        throw PiperServerError.notReady(log: (try? String(contentsOf: logURL, encoding: .utf8)) ?? "")
    }

    public func stop() {
        if let p = process, p.isRunning { p.terminate() }
        process = nil
    }
}

@MainActor
public final class AudioOut: NSObject, AVAudioPlayerDelegate {
    private var player: AVAudioPlayer?
    private var finished: CheckedContinuation<Void, Never>?

    public override init() {}

    public func play(data: Data) async throws {
        try await play(AVAudioPlayer(data: data))
    }

    public func play(url: URL) async throws {
        try await play(AVAudioPlayer(contentsOf: url))
    }

    private func play(_ p: AVAudioPlayer) async {
        stop()
        p.delegate = self
        player = p
        await withCheckedContinuation { (c: CheckedContinuation<Void, Never>) in
            finished = c
            if !p.play() { finish() }
        }
    }

    public func stop() {
        player?.stop()
        finish()
    }

    private func finish() {
        player = nil
        finished?.resume()
        finished = nil
    }

    nonisolated public func audioPlayerDidFinishPlaying(_ player: AVAudioPlayer, successfully flag: Bool) {
        Task { @MainActor in self.finish() }
    }

    nonisolated public func audioPlayerDecodeErrorDidOccur(_ player: AVAudioPlayer, error: Error?) {
        Task { @MainActor in self.finish() }
    }
}

import AVFoundation
import Foundation
import Speech

public enum SpeechError: Error, CustomStringConvertible {
    case noAudioFormat
    case micDenied

    public var description: String {
        switch self {
        case .noAudioFormat: return "Speech recogniser offered no audio format."
        case .micDenied: return "Microphone access denied. Allow it in System Settings → Privacy & Security → Microphone."
        }
    }
}

/// Apple's on-device recogniser (SpeechAnalyzer, macOS 26+). For ml-IN it writes
/// Malayalam in Latin letters ("gadi ennu enth pani cheyyanam").
public enum SpeechModels {
    static func transcriber(_ localeID: String) -> SpeechTranscriber {
        SpeechTranscriber(locale: Locale(identifier: localeID), transcriptionOptions: [],
                          reportingOptions: [.volatileResults], attributeOptions: [])
    }

    /// Downloads the language model if needed (one-time, ~a few hundred MB, system-managed).
    public static func ensureInstalled(localeID: String) async throws {
        let t = transcriber(localeID)
        if let request = try await AssetInventory.assetInstallationRequest(supporting: [t]) {
            try await request.downloadAndInstall()
        }
    }

    /// Transcribes an audio file. Used by `gedi-debug transcribe` and for wake-word calibration.
    public static func transcribe(file url: URL, localeID: String) async throws -> String {
        let t = transcriber(localeID)
        try await ensureInstalled(localeID: localeID)
        let analyzer = SpeechAnalyzer(modules: [t])
        let file = try AVAudioFile(forReading: url)
        let reader = Task {
            var finals: [String] = []
            for try await r in t.results where r.isFinal { finals.append(String(r.text.characters)) }
            return finals.joined(separator: " ")
        }
        if let last = try await analyzer.analyzeSequence(from: file) {
            try await analyzer.finalizeAndFinish(through: last)
        } else {
            await analyzer.cancelAndFinishNow()
        }
        return try await reader.value
    }

    public static func requestMicAccess() async -> Bool {
        await AVCaptureDevice.requestAccess(for: .audio)
    }
}

/// Always-on microphone → SpeechAnalyzer. Calls `onResult(text, isFinal)` from a
/// background task for every recogniser update, and `onStop(error)` if the stream ends.
public final class LiveTranscriber: @unchecked Sendable {
    private let engine = AVAudioEngine()
    private var analyzer: SpeechAnalyzer?
    private var input: AsyncStream<AnalyzerInput>.Continuation?
    private var converter: AVAudioConverter?
    private var resultsTask: Task<Void, Never>?

    public init() {}

    public func start(
        localeID: String,
        onResult: @escaping @Sendable (String, Bool) -> Void,
        onStop: @escaping @Sendable (Error?) -> Void
    ) async throws {
        guard await SpeechModels.requestMicAccess() else { throw SpeechError.micDenied }
        try await SpeechModels.ensureInstalled(localeID: localeID)
        let transcriber = SpeechModels.transcriber(localeID)
        let analyzer = SpeechAnalyzer(modules: [transcriber])
        self.analyzer = analyzer
        guard let target = await SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith: [transcriber]) else {
            throw SpeechError.noAudioFormat
        }

        let (stream, continuation) = AsyncStream.makeStream(of: AnalyzerInput.self)
        input = continuation
        resultsTask = Task {
            do {
                for try await r in transcriber.results { onResult(String(r.text.characters), r.isFinal) }
                onStop(nil)
            } catch {
                onStop(error)
            }
        }
        try await analyzer.start(inputSequence: stream)

        let node = engine.inputNode
        let micFormat = node.outputFormat(forBus: 0)
        converter = AVAudioConverter(from: micFormat, to: target)
        node.installTap(onBus: 0, bufferSize: 4096, format: micFormat) { [weak self] buffer, _ in
            self?.feed(buffer, from: micFormat, to: target)
        }
        engine.prepare()
        try engine.start()
    }

    private func feed(_ buffer: AVAudioPCMBuffer, from source: AVAudioFormat, to target: AVAudioFormat) {
        guard let converter else { return }
        let capacity = AVAudioFrameCount(Double(buffer.frameLength) * target.sampleRate / source.sampleRate) + 1
        guard let out = AVAudioPCMBuffer(pcmFormat: target, frameCapacity: capacity) else { return }
        var consumed = false
        var error: NSError?
        converter.convert(to: out, error: &error) { _, status in
            if consumed {
                status.pointee = .noDataNow
                return nil
            }
            consumed = true
            status.pointee = .haveData
            return buffer
        }
        if error == nil, out.frameLength > 0 { input?.yield(AnalyzerInput(buffer: out)) }
    }

    public func stop() async {
        engine.inputNode.removeTap(onBus: 0)
        engine.stop()
        input?.finish()
        input = nil
        try? await analyzer?.finalizeAndFinishThroughEndOfInput()
        resultsTask?.cancel()
        analyzer = nil
    }
}

/// Reads the frontmost app and, for Chrome/Safari, the active tab's URL and title.
/// Only the frontmost browser is queried, so AppleScript never launches a browser.

    public init() {}

    public func snapshot() -> ActivitySnapshot? {
        guard let app = NSWorkspace.shared.frontmostApplication else { return nil }
        let bundleID = app.bundleIdentifier ?? ""
        var snap = ActivitySnapshot(appName: app.localizedName ?? bundleID, bundleID: bundleID)
        switch bundleID {
        case "com.google.Chrome":
            (snap.url, snap.title) = Self.run("tell application id \"com.google.Chrome\" to get {URL, title} of active tab of front window")
        case "com.apple.Safari":
            (snap.url, snap.title) = Self.run("tell application id \"com.apple.Safari\" to get {URL, name} of front document")
        default:
            break
        }
        return snap
    }

    /// Runs a script returning a two-item list. (nil, nil) on any error, e.g. no windows
    /// open or Automation permission denied.
    private static func run(_ source: String) -> (String?, String?) {
        var error: NSDictionary?
        guard let result = NSAppleScript(source: source)?.executeAndReturnError(&error),
              result.numberOfItems == 2 else { return (nil, nil) }
        return (result.atIndex(1)?.stringValue, result.atIndex(2)?.stringValue)
    }
}

import GediCore

/// `gedi-debug <command>`: exercise one subsystem at a time without the UI.
@main
struct GediDebug {
    static let usage = """
    usage: gedi-debug <command>
      persona                         print the built-in persona (setup copies it to Application Support)
      install-speech [locale]         download Apple's speech model (default ml-IN)
      transcribe <file> [locale]      transcribe an audio file
      say <text> [--out file.wav]     speak Malayalam text with Piper (or save the WAV)
      comment <activity> [--model m]  ask the LLM for an unprompted comment
      reply <utterance> [activity] [--model m]   ask the LLM to answer the user
      activity [seconds]              print the classified frontmost activity every 2 s
      listen [seconds]                live mic: print transcripts and wake/utterance events
    """

    @MainActor
    static func main() async {
        var args = Array(CommandLine.arguments.dropFirst())
        guard !args.isEmpty else { fail(usage) }
        let command = args.removeFirst()
        do {
            var config = try GediConfig.load(from: GediPaths.configFile)
            if let i = args.firstIndex(of: "--model"), i + 1 < args.count {
                config.model = args[i + 1]
                args.removeSubrange(i...(i + 1))
            }
            switch command {
            case "persona": print(Persona.defaultText)
            case "install-speech": try await installSpeech(args.first ?? config.localeID)
            case "transcribe": try await transcribe(args, config)
            case "say": try await say(args, config)
            case "comment": try await comment(args, config)
            case "reply": try await reply(args, config)
            case "activity": try await activity(Double(args.first ?? "") ?? 30)
            case "listen": try await listen(Double(args.first ?? "") ?? 60, config)
            default: fail(usage)
            }
        } catch {
            fail("error: \(error)")
        }
    }

    static func fail(_ message: String) -> Never {
        FileHandle.standardError.write(Data((message + "\n").utf8))
        exit(1)
    }

    static func installSpeech(_ locale: String) async throws {
        try await SpeechModels.ensureInstalled(localeID: locale)
        print("speech model installed for \(locale)")
    }

    static func transcribe(_ args: [String], _ config: GediConfig) async throws {
        guard let path = args.first else { fail(usage) }
        let start = Date()
        let text = try await SpeechModels.transcribe(file: URL(fileURLWithPath: path), localeID: args.dropFirst().first ?? config.localeID)
        print(text)
        print(String(format: "(%.2fs)", Date().timeIntervalSince(start)))
    }

    @MainActor
    static func say(_ args: [String], _ config: GediConfig) async throws {
        var args = args
        var out: String?
        if let i = args.firstIndex(of: "--out"), i + 1 < args.count {
            out = args[i + 1]
            args.removeSubrange(i...(i + 1))
        }
        guard let text = args.first else { fail(usage) }
        let server = PiperServer(config: config)
        try await server.start()
        let start = Date()
        let wav = try await server.client.synthesize(text)
        print(String(format: "synthesised %d bytes in %.2fs", wav.count, Date().timeIntervalSince(start)))
        if let out {
            try wav.write(to: URL(fileURLWithPath: out))
            print("wrote \(out)")
        } else {
            try await AudioOut().play(data: wav)
        }
        server.stop()
    }

    static func brain(_ config: GediConfig) throws -> GediBrain {
        let clips = try ClipLibrary.load(from: GediPaths.clipsDir)
        let persona = Persona.load(from: GediPaths.personaFile)
        return GediBrain(model: OllamaClient(baseURL: config.ollamaURL, model: config.model),
                         builder: PromptBuilder(persona: persona, clips: clips.clips))
    }

    static func comment(_ args: [String], _ config: GediConfig) async throws {
        guard let activity = args.first else { fail(usage) }
        let start = Date()
        let r = try await brain(config).comment(activity: activity)
        print(String(format: "[%@, %.1fs] %@", config.model, Date().timeIntervalSince(start), String(describing: r)))
    }

    static func reply(_ args: [String], _ config: GediConfig) async throws {
        guard let utterance = args.first else { fail(usage) }
        let activity = args.dropFirst().first ?? "Now: Visual Studio Code (for 5 min straight)"
        let start = Date()
        let r = try await brain(config).reply(to: utterance, activity: activity)
        print(String(format: "[%@, %.1fs] %@", config.model, Date().timeIntervalSince(start), String(describing: r)))
    }

    @MainActor
    static func activity(_ seconds: Double) async throws {
        let probe = ActivityProbe()
        var log = ActivityLog()
        let end = Date().addingTimeInterval(seconds)
        while Date() < end {
            if let snap = probe.snapshot() {
                let a = ActivityClassifier.classify(snap)
                log.record(a, at: Date())
                print("\(a.kind.rawValue)\t\(a.name)\t\(a.detail ?? "")\t\(snap.url ?? "")")
            }
            try await Task.sleep(for: .seconds(2))
        }
        print("---\n" + log.summary(now: Date()).promptText())
    }

    @MainActor
    static func listen(_ seconds: Double, _ config: GediConfig) async throws {
        let session = ListenSessionBox(ListenSession(
            matcher: WakeWordMatcher(wakeWords: config.wakeWords),
            silence: config.silenceSeconds, followUpWindow: config.followUpSeconds))
        let mic = LiveTranscriber()
        try await mic.start(localeID: config.localeID, onResult: { text, isFinal in
            Task { @MainActor in
                print(isFinal ? "FINAL    \(text)" : "partial  \(text)")
                if let e = session.value.heard(text, isFinal: isFinal, at: Date()) { print(">>> \(e)") }
            }
        }, onStop: { error in
            Task { @MainActor in print("recogniser stopped: \(String(describing: error))") }
        })
        print("listening for \(Int(seconds)) s, say \"gedeee\" then a sentence…")
        let end = Date().addingTimeInterval(seconds)
        while Date() < end {
            if let e = session.value.tick(at: Date()) {
                print(">>> \(e)")
                if case .utterance = e { session.value.speakingEnded(at: Date()) }  // no reply here; open follow-up
            }
            try await Task.sleep(for: .milliseconds(250))
        }
        await mic.stop()
    }
}

    var value: ListenSession
    init(_ value: ListenSession) { self.value = value }
}

@Observable
@MainActor
final class StageModel {

/// Transparent, click-through, always-on-top strip along the bottom of the screen.
final class OverlayPanel: NSPanel {
    init(frame: NSRect) {
        super.init(contentRect: frame, styleMask: [.borderless, .nonactivatingPanel], backing: .buffered, defer: false)
        isOpaque = false
        backgroundColor = .clear
        hasShadow = false
        level = .statusBar
        ignoresMouseEvents = true
        collectionBehavior = [.canJoinAllSpaces, .stationary, .fullScreenAuxiliary, .ignoresCycle]
    }

    override var canBecomeKey: Bool { false }
    override var canBecomeMain: Bool { false }
}

@MainActor
final class OverlayController {
    static let height: CGFloat = 240
    private let panel: OverlayPanel
    private let stage: StageModel
    private var timer: Timer?
    private var lastStep = Date()
    private var rng = SystemRandomNumberGenerator()

    init(stage: StageModel) {
        self.stage = stage
        panel = OverlayPanel(frame: Self.frameForMainScreen())
        panel.contentView = NSHostingView(rootView: StageView(stage: stage))
        NotificationCenter.default.addObserver(
            forName: NSApplication.didChangeScreenParametersNotification, object: nil, queue: .main
        ) { [weak self] _ in
            MainActor.assumeIsolated { self?.panel.setFrame(Self.frameForMainScreen(), display: true) }
        }
    }

    /// Bottom strip of the main screen's visible area, i.e. just above the Dock.
    static func frameForMainScreen() -> NSRect {
        let visible = (NSScreen.main ?? NSScreen.screens[0]).visibleFrame
        return NSRect(x: visible.minX, y: visible.minY, width: visible.width, height: height)
    }

    func show() {
        panel.orderFrontRegardless()
        lastStep = Date()
        timer = Timer.scheduledTimer(withTimeInterval: 1.0 / 30, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.step() }
        }
    }

    private func step() {
        let now = Date()
        let dt = min(now.timeIntervalSince(lastStep), 0.1)
        lastStep = now
        let maxX = Double(panel.frame.width) - StageView.spriteWidth
        stage.walker.step(dt: dt, minX: 0, maxX: maxX, random: &rng)
    }
}

struct StageView: View {
    static let pixel: CGFloat = 4
    static let spriteWidth = Double(SpriteArt.width) * Double(pixel)
    static let spriteHeight = Double(SpriteArt.height) * Double(pixel)
    static let bubbleWidth: Double = 320

    let stage: StageModel

    var body: some View {
        GeometryReader { geo in
            ZStack(alignment: .bottomLeading) {
                Color.clear
                SpriteView(frame: stage.walker.frame, facingRight: stage.walker.facingRight)
                    .offset(x: stage.walker.x)
                if let text = stage.bubble {
                    BubbleView(text: text)
                        .frame(maxWidth: Self.bubbleWidth, alignment: .leading)
                        .fixedSize(horizontal: false, vertical: true)
                        .offset(x: bubbleX(width: geo.size.width), y: -(Self.spriteHeight + 8))
                }
            }
        }
    }

    /// Keep the bubble over Gedi but fully on screen.
    private func bubbleX(width: Double) -> Double {
        min(max(stage.walker.x - 40, 0), max(width - Self.bubbleWidth, 0))
    }
}

struct SpriteView: View {
    let frame: SpriteFrame
    let facingRight: Bool

    var body: some View {
        Canvas { ctx, _ in
            let p = StageView.pixel
            for (y, row) in SpriteArt.rows(frame).enumerated() {
                for (x, ch) in row.enumerated() {
                    guard let rgb = SpriteArt.palette[ch] else { continue }
                    let rect = CGRect(x: CGFloat(x) * p, y: CGFloat(y) * p, width: p, height: p)
                    ctx.fill(Path(rect), with: .color(Color(rgb: rgb)))
                }
            }
        }
        .frame(width: StageView.spriteWidth, height: StageView.spriteHeight)
        .scaleEffect(x: facingRight ? 1 : -1, y: 1)
    }
}

struct BubbleView: View {
    let text: String

    var body: some View {
        Text(text)
            .font(.system(size: 15, weight: .medium))
            .foregroundStyle(Color.black)
            .padding(.horizontal, 12)
            .padding(.vertical, 8)
            .background(RoundedRectangle(cornerRadius: 12).fill(Color.white))
            .overlay(RoundedRectangle(cornerRadius: 12).stroke(Color.black.opacity(0.25)))
            .shadow(radius: 3)
    }
}

extension Color {
    init(rgb: UInt32) {
        self.init(red: Double((rgb >> 16) & 0xFF) / 255,
                  green: Double((rgb >> 8) & 0xFF) / 255,
                  blue: Double(rgb & 0xFF) / 255)
    }

```swift
import AppKit
import GediCore
import GediSystem
import os

private let log = Logger(subsystem: "com.mahadevan.gedi", category: "app")

/// Wires everything together:
///   every 5 s    → read frontmost app/tab → ActivityLog
///   every 0.25 s → ListenSession.tick, and a timed comment when CommentPolicy says so
///   mic results  → ListenSession → wake chime / reply to the user
@MainActor
final class GediController {
    private let config: GediConfig
    private let stage = StageModel()
    private var overlay: OverlayController?
    private var menu: StatusMenu?
    private let piper: PiperServer
    private let voice: GediVoice
    private let brain: GediBrain
    private let probe = ActivityProbe()
    private var activityLog = ActivityLog()
    private var listen: ListenSession
    private let mic = LiveTranscriber()
    private let policy: CommentPolicy
    private var quiet = CommentPolicy.State()
    private var commentInFlight = false
    private var replyInFlight = false
    private var speaking = false
    private var lastSpokeAt = Date()
    private var timers: [Timer] = []

    init() throws {
        config = try GediConfig.load(from: GediPaths.configFile)
        let clips: ClipLibrary
        do {
            clips = try ClipLibrary.load(from: GediPaths.clipsDir)
        } catch {
            log.error("clips.json is malformed, ignoring clips: \(String(describing: error), privacy: .public)")
            clips = .empty(at: GediPaths.clipsDir)
        }
        piper = PiperServer(config: config)
        voice = GediVoice(piper: piper.client, clips: clips)
        brain = GediBrain(
            model: OllamaClient(baseURL: config.ollamaURL, model: config.model),
            builder: PromptBuilder(persona: Persona.load(from: GediPaths.personaFile), clips: clips.clips))
        listen = ListenSession(
            matcher: WakeWordMatcher(wakeWords: config.wakeWords),
            silence: config.silenceSeconds, followUpWindow: config.followUpSeconds)
        policy = CommentPolicy(interval: config.commentIntervalSeconds)
    }

    func start() {
        let overlay = OverlayController(stage: stage)
        overlay.show()
        self.overlay = overlay
        menu = StatusMenu(
            onMuteChanged: { [weak self] muted in self?.quiet.muted = muted },
            onCommentNow: { [weak self] in Task { await self?.comment() } })
        show("ഗഡി എത്തീട്ടാ.", for: 4)
        timers.append(Timer.scheduledTimer(withTimeInterval: 5, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.sampleActivity() }
        })
        timers.append(Timer.scheduledTimer(withTimeInterval: 0.25, repeats: true) { [weak self] _ in
            MainActor.assumeIsolated { self?.tick() }
        })
        sampleActivity()
        lastSpokeAt = Date()
        Task { await startServices() }
    }

    func shutdown() {
        timers.forEach { $0.invalidate() }
        piper.stop()
    }

    // MARK: services

    private func startServices() async {
        do {
            try await piper.start()
        } catch {
            log.error("piper: \(String(describing: error), privacy: .public)")
            show("Piper start aayilla. scripts/setup.sh run cheyy.", for: 10)
        }
        await startMic()
    }

    private func startMic() async {
        do {
            try await mic.start(
                localeID: config.localeID,
                onResult: { [weak self] text, isFinal in
                    Task { @MainActor in self?.heard(text, isFinal: isFinal) }
                },
                onStop: { [weak self] error in
                    Task { @MainActor in self?.micStopped(error) }
                })
            log.info("listening (\(self.config.localeID, privacy: .public))")
        } catch {
            log.error("mic: \(String(describing: error), privacy: .public)")
            show("മൈക്ക് കിട്ടിയില്ല ഗഡീ.", for: 8)
        }
    }

    /// The recogniser stream ended (error or system interruption): restart it.
    private func micStopped(_ error: Error?) {
        log.error("recogniser stopped: \(String(describing: error), privacy: .public); restarting")
        Task {
            await mic.stop()
            try? await Task.sleep(for: .seconds(2))
            await startMic()
        }
    }

    // MARK: loop

    private func sampleActivity() {
        guard let snap = probe.snapshot() else { return }
        activityLog.record(ActivityClassifier.classify(snap), at: Date())
        quiet.inCall = activityLog.current(now: Date())?.kind == .call
    }

    private func tick() {
        let now = Date()
        if let event = listen.tick(at: now) { handle(event) }
        quiet.conversing = listen.phase != .idle
        quiet.busy = commentInFlight || replyInFlight || speaking
        if policy.isDue(now: now, lastSpokeAt: lastSpokeAt, state: quiet) {
            Task { await comment() }
        }
    }

    private func heard(_ text: String, isFinal: Bool) {
        if let event = listen.heard(text, isFinal: isFinal, at: Date()) { handle(event) }
    }

    private func handle(_ event: ListenEvent) {
        switch event {
        case .wake:
            log.info("wake")
            NSSound(named: "Tink")?.play()
            stage.bubble = "പറ ഗഡീ…"
        case .utterance(let text):
            log.info("utterance: \(text, privacy: .public)")
            stage.bubble = "ഹ്മ്…"
            Task { await reply(to: text) }
        case .gaveUp:
            if stage.bubble == "പറ ഗഡീ…" { stage.bubble = nil }
            Task { await brain.endConversation() }
        }
    }

    // MARK: talking

    private var activityText: String {
        activityLog.summary(now: Date()).promptText()
    }

    private func comment() async {
        guard !commentInFlight, !replyInFlight, !speaking else { return }
        commentInFlight = true
        defer {
            commentInFlight = false
            lastSpokeAt = Date()
        }
        do {
            guard let r = try await brain.comment(activity: activityText), r.speak else { return }
            // The user may have started talking to Gedi while the model was thinking.
            guard listen.phase == .idle else { return }
            await speak(r)
        } catch {
            log.error("comment: \(String(describing: error), privacy: .public)")
        }
    }

    private func reply(to text: String) async {
        replyInFlight = true
        defer {
            replyInFlight = false
            lastSpokeAt = Date()
        }
        do {
            if let r = try await brain.reply(to: text, activity: activityText), r.speak {
                await speak(r)
                return
            }
        } catch {
            log.error("reply: \(String(describing: error), privacy: .public)")
            show("Ollama-ക്ക് എന്തോ പറ്റി ഗഡീ.", for: 6)
        }
        listen.speakingEnded(at: Date())  // nothing said; still open the follow-up window
    }

    private func speak(_ r: GediReply) async {
        while speaking { try? await Task.sleep(for: .milliseconds(100)) }
        speaking = true
        let text = voice.displayText(for: r)
        stage.bubble = text
        stage.setTalking(true)
        listen.speakingStarted()
        do {
            try await voice.say(r)
        } catch {
            log.error("speak: \(String(describing: error), privacy: .public)")
        }
        listen.speakingEnded(at: Date())
        stage.setTalking(false)
        speaking = false
        hideBubble(ifStill: text, after: 3)
    }

    private func show(_ text: String, for seconds: Double) {
        stage.bubble = text
        hideBubble(ifStill: text, after: seconds)
    }

    private func hideBubble(ifStill text: String, after seconds: Double) {
        Task {
            try? await Task.sleep(for: .seconds(seconds))
            if stage.bubble == text { stage.bubble = nil }
        }
    }
}
